### The `Class`
- A class is a blueprint or template based on which objects are created. A class itself is not an object.

### The `object`
- An object is created based on a class, object is an instance of a class.

- Syntax for creating a class:

```
class ClassName:
    ...
```

- Use pascal case for naming class:
    -> Pascal case: StudentInfo
    -> Camel case: studentInfo
    -> Snake case: student_info
    -> kebab case: student-info

### Referrencing attributes of an object:
-> Reading / getting the value:
    object_name.attribute
-> Setting the value:
    object_name.attribute = value

### Referrencing methods of an object
-> Calling the method:
    object_name.method_name([arguments])

### The constructor
-> A  onstructor is a special method which initializes the attributes of an object at the time of creating an object.
-> The name of constructor is: __init__(self[, arguments])
    -> Each argument is used to set a value for an object's attribute.
-> The 'self' is always a first parameter (argument) of any method in a class, referring the object itself.

## Encapsulation
We can hide the attributes from directly accessing outside of a class.
This is called encapsulation or data hiding.

When you hide access to the attributes from outside then those attributes are private attributes.
When the atrributes are accessible from outside then they are public attributes.

To make an attribute private just add double underscore in front of the attribute name.

Public attribute            Private attribute
-------------------         ------------------
value                       __value
list                        __list

However, we can access the hidden attributes using public methods.
There are two types of methods to work with private attributes:
    - Getter methods: read (get) the value of a private attribute`
    - Setter methods: write (set) the value of a private attribute
